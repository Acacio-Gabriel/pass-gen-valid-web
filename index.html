Noções Básicas de criptografia

O que é uma senha forte?

Uma senha forte é aquela que possui uma combinação de caracteres maiúsculos, minúsculos, números e símbolos, tornando-a difícil de ser quebrada por métodos automatizados.

O que é um hash SHA-256?

SHA-256 é uma função hash criptográfica que transforma qualquer entrada (como uma senha) em uma sequência de 64 caracteres hexadecimais. É uma função de mão única: não é possivel reverter o hash para obter a senha original. Isso é usado para armazenar senhas com segurança: em vez de quardar a senha em texto claro, sistemas armazenam apenas o hash.

Por que usar hash e não armazenar senhas em texto claro?

Armazenar senhas em texto claro é extremamente perigoso, pois se os dados forem comprometidos, todas as senhas estarão expostas. Usar hashes garante que, mesmo que os dados sejam acessados, as senhas originais não possam ser obtidas facilmente.
